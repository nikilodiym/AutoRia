# 🚗 AutoRia Clone

A web application developed with Django that replicates the basic functionality of the AutoRia platform. The project allows users to browse, search, filter, and manage car advertisements through a modern and user-friendly interface.

---

## 📖 About the Project

AutoRia Clone is an educational project created to practice full-stack web development using Django.

The application provides functionality for viewing vehicle advertisements, searching for cars using filters, user authentication, and an administrative panel for managing data.

---

## ✨ Features

- 🔐 User registration and login
- 👤 Personal user account
- 🚗 View all car advertisements
- 🔍 Search and filtering system
- ➕ Create new advertisements
- ✏️ Edit advertisements
- 🗑 Delete advertisements
- 📱 Responsive interface
- 🛠 Django Administration Panel

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/nikilodiym/AutoRia.git
```

Open the project

```bash
cd AutoRia
```

Create virtual environment

```bash
python -m venv .venv
```

Activate it

Windows

```bash
.venv\Scripts\activate
```

Linux / macOS

```bash
source .venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run migrations

```bash
python manage.py migrate
```

Start the server

```bash
python manage.py runserver
```

Open in browser

```
http://127.0.0.1:8000/
```
